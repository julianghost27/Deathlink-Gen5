# Pokemon-Black-Soul-Link-Tracker
-- Linked-faint script for two-player Pokemon Nuzlocke runs in BizHawk. 
-- Pokemon are paired by the number at the end of their nickname (A22 = B22). 
-- When one faints, the partner with the same number is set to 0 HP.
Python: Tiny HTTP relay for linked_faint.lua: stores faint events in memory and hands them to the other player's script.
